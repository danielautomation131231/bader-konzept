# Lernzentrum Bader – Design-Konzeptstudie

Unverbindliche Konzeptstudie für einen möglichen neuen Webauftritt des Lernzentrums Bader (Offenbach).
Dies ist nicht die offizielle Website des Unternehmens.

## Lokal starten

```bash
npm install
npm run dev
```

Produktions-Build: `npm run build` (Ausgabe in `docs/` für GitHub Pages).
